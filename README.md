Hi there! Welcome to a little operating system I’ve been coding in my spare time over the last five days. If there are bugs, expect updates every two days to two months; if it runs well, there will be zero updates. It supports dual-CPU and GPU setups via LAN. If you're wondering who I am, check out my YouTube or Twitch channels under the name "Zoviloplay." It supports the Android App Store (pre-installed, requires an internet connection) as well as OBS and screen sharing.
